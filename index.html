Nearchos Potamitis

PhD student, Department of Computer Science, Aarhus University

I work on how large language models reason, supervised by Akhil Arora and Lars Klein. My aim is to make that reasoning, as Daft Punk would put it, harder, better, faster, stronger. Before Aarhus I studied electrical engineering and then data science at EPFL, where my master's thesis at DLAB became Fleet of Agents.

Selected papers

Fleet of Agents: Coordinated Problem Solving with Large Language Models

Lars Klein*, Nearchos Potamitis*, Roland Aydin, Robert West, Caglar Gulcehre, Akhil Arora

ICML 2025 * equal contribution

A group of LLM agents explore a problem as a dynamic tree search, using genetic-type particle filtering to decide which branches deserve more compute.

CacheSaver: A Modular Framework for Efficient, Affordable, and Reproducible LLM Inference

Nearchos Potamitis*, Lars Klein*, Bardia Mohammadi, Attreyee Mokherjee, Chongyang Xu, Laurent Bindschaedler, Niket Tandon, Akhil Arora

Findings of EMNLP 2025 * equal contribution

An asynchronous, batched request layer that sits between your code and the LLM, cutting cost and latency while keeping experiments reproducible.

Current Advances in LLM Reasoning

Akhil Arora, Vishrav Chaudhary, Julia Kreutzer, Nearchos Potamitis, Nouha Dziri, Niket Tandon

Tutorial, ACL 2026 and IJCAI-ECAI 2026

A tutorial on where LLM reasoning stands today: how models are trained and prompted to reason, how that reasoning is evaluated, and what remains open.

Atomix: Timely, Transactional Tool Use for Reliable Agentic Workflows

Bardia Mohammadi*, Nearchos Potamitis, Lars Klein, Akhil Arora, Laurent Bindschaedler

ICLR 2026 workshops

Treats an agent's tool calls like database transactions, so that a multi-step workflow can be kept consistent and recovered when a step fails.

ReasonBench: Benchmarking the (In)Stability of LLM Reasoning

Nearchos Potamitis*, V. Ramani*, H. A. Arora, D. Kuchhal, Lars Klein, Akhil Arora

REALM Workshop, EMNLP 2026 (spotlight) * equal contribution

A benchmark for how much an LLM's reasoning changes from run to run, so that reliability can be measured instead of assumed.

Are Retrials All You Need? Enhancing Large Language Model Reasoning Without Verbalized Feedback

Nearchos Potamitis, Akhil Arora

REALM Workshop, EMNLP 2026 (spotlight)

Simply retrying a failed reasoning attempt is a surprisingly strong baseline, often matching methods that ask the model to critique itself.

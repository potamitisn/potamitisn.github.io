# content/

Everything personal from the old al-folio site, template-free. Any new site should read from here.

| File | What |
|---|---|
| `profile.yml` | Name, affiliation, advisor, contact handles, site metadata, home-page bio |
| `papers.bib` | Publications (BibTeX with custom fields `abbr`, `selected`, `annotation`, `bibtex_show`) |
| `resume.json` | Full CV in JSON Resume format (work, education, skills, languages, references, projects) |
| `cv.yml` | Same CV in the old al-folio YAML format (kept for reference, `resume.json` is the richer one) |
| `assets/prof_pic.jpg` | Profile photo |
| `assets/favicon.jpg` | Favicon source |
| `assets/cv.pdf` | Downloadable CV |
